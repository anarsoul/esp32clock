esp32clock web installer

Open firmware for the HU-058 LED clock kits with an ESP32-C3 in the 8051's socket: NTP time, alarms, colours, a settings page, Home Assistant over MQTT. — GitHub · Releases

Install

Plug the clock's ESP32-C3 into this computer over USB and press Install. This needs Chrome or Edge on a desktop (Web Serial); Firefox, Safari and phones cannot do it. If the installer cannot connect, hold the BOOT button on the module while plugging it in, then try again.

The installer offers to erase the clock first. Erasing clears the saved settings and the stored network; without it the settings survive. A clock already on your network can be updated from http://<ip>/update with the release's esp32clock-ota-*.bin instead, with no USB.

What the image is configured with

settingin the image
networknone: the clock boots as an access point, see below
timezoneUTC−7 (Vancouver). Set yours on the settings page
API tokenesp32clock; change it on http://<ip>/token once the clock is on your network
everything elsethe defaults: brightness cap 50 %, access point password esp32clock

First boot

  1. The panel shows AP: the clock is a Wi-Fi access point named clock-xxxx, password esp32clock.
  2. Join it from a phone; the setup form opens by itself, or at http://192.168.4.1/.
  3. Pick your network, type its password, set the timezone and a hostname, save. The clock joins the network and shows the time.
  4. Both buttons held 10 s put the clock back into its access point.
