Web installer for the open firmware of the HU-058 LED clock kits with an ESP32-C3 in the 8051's socket: NTP time, alarms with sampled sound, colours, a settings page, Home Assistant over MQTT.

  3. Install

    This browser cannot reach a serial port. Open this page in Chrome or Edge on a desktop computer. The installer works only on an HTTPS page or on localhost.

    The browser asks for a port: the clock's is USB JTAG/serial debug unit. The installer then offers to erase the clock first, see below. Writing takes about a minute.

    The port is not listed, or the installer cannot connect
    • Hold the BOOT button on the module while plugging it in, then try again. After installing that way, unplug the clock and plug it in again to start it.
    • Try another cable: many carry power only.
    • Close anything else that has the port open, a serial monitor for one.
    • On Linux your user needs access to /dev/ttyACM0, usually through the dialout or uucp group.

Settings: kept unless you erase

The installer writes the bootloader, the partition table, the firmware and the default clip pack (the alarm's sampled sounds), and leaves the settings alone. So without the erase a clock keeps its settings and its network; with it they are cleared and the clock starts as new. A clip pack you uploaded from /clips is replaced by the default one either way.

Updating a clock that is on your network

That needs no USB: download the release's onebitdawn-ota-*.bin and upload it on the clock's http://<ip>/system page. The clock shows a PIN on its panel to confirm.

What the image is configured with

Network
None: the clock starts as an access point, see the first boot below.
Timezone
UTC−7 (Vancouver). Set yours in the setup form or on the settings page.
API token
None: updates go from the clock's pages with the PIN on its panel. Set a token on http://<ip>/system to use the scripts.
Everything else
The defaults: brightness up to 50 %, access point password onebitdawn.

First boot

  1. The panel shows AP: the clock is a Wi-Fi access point named clock-xxxx, password onebitdawn.
  2. Join it from a phone. The setup form opens by itself; if it does not, go to http://192.168.4.1/.
  3. Pick your network, type its password, set the timezone and a hostname, and save. The clock joins the network and shows the time.
  4. To get back to the access point later, hold both buttons for 10 seconds.
